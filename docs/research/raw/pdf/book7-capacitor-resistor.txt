 Experiment 20:        Music Composer |
                                                                                     to “compose”
      There are a number of programs in existence which allow full-scale computers
music. Many of these programs are based on one of two fundamen    tal   technique s:
      The “‘functional’’ technique: Specific rules for harmony, rhythm, sequence of notes, etc.
               are programmed           as mathematical       functions.        The computer           is then programmed           to
            generate random numbers; each random number is substituted for a variable in the
            functions. Every random number generated eventually becomes a note.
       The “‘sampling’’ technique: Specific rules for harmony, rhythm, sequence of notes, etc. are
            programmed as mathematical functions. The computer is then programmed to randomly
            select notes; each note is compared against the rules. If a randomly generated note
           does not agree with the rules, it is discarded and another note is selected.
       We     can program            the MINIVAC      to ‘‘compose’’       music    using the “functional”             technique.
